# Раунд 23: черновики ядра сабагентов и адаптеров вендоров

Черновики, а не часть набора: в бандл не входят, тесты репозитория их не запускают. Сведённая редакция войдёт в
ревизию 4.5 после решения владельца; этот каталог тогда уберётся или сократится.

- `core.md` — ядро: правило тщательности, приёмка отчётов координатором, формат отчёта, карточки сабагентов.
- `core-critique.md` — независимая критика ядра: 3 блокера, 17 мажоров, 5 миноров, с предложенным текстом.
  `critic-proto/report_check.py` — прототип механической сверки отчёта (цитаты `файл:строка` и дешёвые команды).
- `routing.md` — правило маршрута сабагентов: свои, CLI другого вендора, вручную через владельца.
- `adapters/<вендор>.md` — адаптер: что это и куда ставить, промпты, сопоставление механизмов, пределы и
  источники, раздел «Проверка». Рядом — файлы для установки (`files/`), прослойки хуков и их тесты.

Вендоры (на 2026-11-24): Codex — OpenAI Codex CLI 0.172.0; Gemini Carbon — модель Gemini 4 Carbon в Antigravity
CLI `agy` 1.5.16; Grok 4.7 Build — Grok Build (`grok`, @xai-official/grok 1.0.92) с моделью Grok 4.7; Kimi 3.1 Pro —
модель Kimi K3.1 Pro в Kimi Code CLI 2.7.3; Qwen 4 Max — модель Qwen4-Max в Qwen Code 0.28.4.

Каждый черновик проверен отдельным агентом по первоисточникам (документация и исходники версии, пакеты npm,
issues), найденные дыры исправлены на месте. Вживую CLI вендоров не запускались: в этой среде нет их ключей.
Хуки проверены на синтетических событиях в формате вендора.
